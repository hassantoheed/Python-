## Projects

### 1. Character Movement System (OOP)

A character movement program developed using Python and Object-Oriented Programming principles.

**Features:**
- Two characters: Jack and Karla.
- Jack moves 10 units in each direction.
- Karla moves 20 units in each direction.
- Character selection and direction input.
- Input validation.
- Position boundaries between 0 and 10,000.

**OOP Concepts Demonstrated:**
- Encapsulation
- Inheritance
- Polymorphism
- Method Overriding
- Constructors
- `super()`
